One funny line, 200 characters or fewer, written to make the judge laugh — an entry for the [make.fun](https://make.fun/bounty/u-email-baru-make-the-judge-laugh-in-one-line-791ccb21) bounty **Make the Judge Laugh in One Line** ($2, 2 places).

## The line

> I told the judge I was innocent, and he laughed so hard he held himself in contempt of court.

## How it works

`main.py` (Python standard library only) writes the line to `/output/entry.txt`, the path the grader reads. It uses a plain `open()` plus an explicit `os.chmod(path, 0o644)` so the output is readable by the grader. `entry.txt` holds the same line for reference.

## Run it

```sh
python3 main.py /output/entry.txt
```
